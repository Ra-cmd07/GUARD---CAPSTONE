## 🚀 Quick Start (3 Steps)

### **1. Update Backend URL**
Edit `src/config/api.ts`:
```typescript
export const API_BASE_URL = 'http://YOUR_IP:5000/api';
```

### **2. Start the App**
```cmd
cd Attendbox-Mobile
npm start
```

### **3. Open on Phone**
- Install **Expo Go** app
- Scan QR code from terminal
- Same WiFi network required
